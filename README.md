## ✨ 這個小工具可以做什麼？

### 🌞 01｜今天是什麼節氣？

你知道今天正處於哪一個節氣嗎？
打開網站，就能查看當前節氣、節氣特色，以及相關的傳統生活養生觀念

從飲食、作息到日常活動，重新認識古人觀察四季的智慧

### 📚 02｜探索完整的二十四節氣

從立春到大寒，探索一年中的二十四個節氣。
了解不同節氣的文化背景、季節變化、傳統飲食與生活習俗。

讓節氣不再只是日曆上的兩個字，而是認識自然與生活的另一種方式。

### 📖 03｜寫下自己的養生日誌

今天喝水了嗎?睡得好嗎?心情和身體感受如何?
不需要寫長篇日記，也能透過簡單的紀錄，慢慢認識自己的生活狀態。

支援：

- 💧 喝水、蔬菜、睡眠與運動紀錄
- ✍️ 個人備註與身體感受
- 📅 補填過去日期的日誌
- 🔎 搜尋與回顧歷史紀錄
- 📊 觀察日常生活習慣

**不是為了每天都做到滿分，而是看見自己一點一滴的改變。**

### 🧬 04｜探索自己的體質傾向

透過 18 題生活觀察問卷，認識傳統中醫9種體質分類的概念。
完成問卷後，可以查看體質傾向結果與日常生活觀察建議，也能自行選擇是否將結果加入個人日誌

是一項自我觀察工具，**不具備醫療診斷或臨床評估功能**。

### ⏰ 05｜讓生活習慣更容易持續

內建實用的小工具，讓養生融入日常：

- 🗓️ 下一個節氣倒數
- ⏳ 日常計時工具
- ✅ 每日生活習慣打卡
- 🔄 日誌與習慣紀錄連動

不用一次改變所有生活方式，從一個小習慣開始就好。

### 📱 06｜像 App 一樣使用

這是一個支援 PWA（漸進式網頁應用程式）的網站。
可以透過支援的瀏覽器加入手機主畫面，像一般 App 一樣開啟。
部分已快取內容也能離線瀏覽，實際可用範圍依瀏覽器及快取狀態而定。

## 🔐 你的紀錄，優先由你保管

我們認為，個人的生活與健康相關紀錄值得被好好保護。
因此，本專案採用**本機優先儲存**的方式：

- 不需要建立帳號
- 日誌與習慣紀錄儲存在目前使用的瀏覽器
- 提供 JSON 備份與還原功能
- 不需要將日誌上傳到帳號才能使用

**⚠️ 重要提醒：**

清除瀏覽器資料、更換裝置或使用無痕模式，都可能造成紀錄遺失。建議定期下載備份。
備份 JSON 檔案沒有加密，請妥善保管，避免公開分享。

## 🛠️ 技術與開發

是一個以原生網頁技術打造的輕量級開源專案。

| 項目 | 使用技術 |
|---|---|
| 網頁結構 | HTML5 |
| 視覺設計 | CSS3 / RWD |
| 互動功能 | Vanilla JavaScript |
| 本機資料 | LocalStorage |
| 離線支援 | Service Worker / PWA |
| 網站部署 | GitHub Pages |

不依賴大型前端框架，希望保持網站輕量、容易理解，也方便持續維護。

## ⚠️ 健康資訊與醫療免責聲明

本網站提供節氣文化介紹、生活習慣紀錄、傳統養生資訊及非診斷性的體質傾向問卷。

所有內容僅供文化學習、一般資訊參考與個人生活觀察使用，**不構成醫療診斷、治療、處方或個別化醫療建議**。

傳統穴位、飲食及養生觀念不代表具有經臨床證實的治療效果。

若有身體不適、慢性疾病、懷孕、正在服藥或其他特殊健康情況，請諮詢合格醫療專業人員。請勿因本站內容延後就醫或自行停藥。
